## How we work

- **Branches:** one branch per issue, named after the issue number, for example `12-near-me-now`.
- **Commits:** small, in the imperative mood, with the issue number, for example `Add near-me filter to event list (#12)`.
- **Pull requests:** every change reaches `main` through a pull request with one teammate's approval. Write `Closes #12` in the description.
- **Done:** a story is done only when it meets its acceptance criteria and our [Definition of Done](docs/definition-of-done.md).
- **Sprints:** see the [sprint rules](docs/sprint-rules.md) for dates and what is checked at each review.
